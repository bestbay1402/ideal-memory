# 실행 검증 기록

검증일: 2026-11-04. 로컬 클라우드 작업 공간에서 실행했습니다. 실제 Supabase 계정이나 공개 배포 주소에 대한 결과는 아닙니다.

## 자동 검증

- `npm test`: 엔진·서버·데이터베이스·채팅 69개 통과.
- `npm run typecheck`: 통과.
- `npm run build`: 최적화 빌드 및 Next.js 타입 검사 통과.
- `npm run test:e2e`: Chromium 브라우저 시나리오 5개 통과.
- `npm run balance -- --check`: 모든 기준 통과.
- `npm run start`: 배포용 서버 HTTP200, 실제 Chromium 캐릭터 생성·키보드 이동 확인, 브라우저 실행 오류0건.

브라우저 검사는 실제 화면에서 기사/요정 생성, WASD 이동, 몬스터 선택·자동 접근·처치, 보상과 처치 수, 구매·강화·초록 물약, 지역 제한, 새로고침 저장 복구를 검증합니다. 99레벨 검사는 테스트 전용 로컬 데모 저장을 준비한 후 실제 캔버스 공격을 수행하여 10마리 처치에 누적 수가 10 증가하는지 확인했습니다.

랭킹 UI 검사는 표시용 API 응답을 격리된 테스트에서만 제공합니다. 프로덕션/데모 랭킹에 가짜 캐릭터를 추가하지 않습니다. 실제 전투력 정렬과 저장은 별도 PostgreSQL 테스트로 검증합니다.

PGlite 테스트는 실제 PostgreSQL 엔진에 마이그레이션 SQL을 적용하여 권한, 닉네임 유일성, 행 버전 경쟁, 요청 중복 방지, 계정 분리, 처치 수 유지/집계, 채팅100개 제한, 도배 제한, 시스템 알림을 검증합니다. Supabase 자체 Auth와 Realtime 네트워크 서비스는 로컬 테스트용 스키마/함수로 대체하므로 실제 연결 검증과 구분합니다.

## 남은 외부 확인

실제 Supabase URL/키와 계정이 제공되지 않아 회원가입 이메일, 다른 컴퓨터의 로그인 복원, 실제 두 계정 사이의 Broadcast/Presence 전달은 아직 실행하지 못했습니다. README의 연결 절차 후 확인해야 합니다. 코드·SQL·로컬 데모는 준비되어 있으며, 배포와 환경 게시를 수행하지 않았습니다.

## 회원가입 연결 진단 개선 (2026-11-04)

- 인증 REST 요청을 동일 게임 주소의 `/api/auth`로 전달하여 브라우저의 외부 인증 도메인 직접 연결 의존도를 줄였습니다.
- `/connection`에서 주소·키 종류/프로젝트 일치·이메일 가입 설정·DB 설치 상태를 조회할 수 있습니다. 비밀 키와 사용자 계정 내용은 응답에 포함되지 않습니다.
- `npm test`: 110개 통과. 실제 Supabase SDK를 사용한 가입/로그인/토큰 갱신/로그아웃 흐름을 모의 업스트림으로 검증했습니다. 실제 계정을 생성하지 않았습니다.
- `npm run test:e2e`: 8개 통과. 기존 게임5개와 연결 진단3개입니다.
- 실제 배포에 등록된 Supabase URL/키의 연결 성공 여부는 진단 페이지에서 별도로 확인해야 합니다. 수정 자체로 잘못된 프로젝트 주소나 중지된 프로젝트가 복구되는 것은 아닙니다.

## 로컬 플레이 + 10분 체크포인트 저장 (2026-11-05)

사용자가 선택한 방식으로 온라인 이동·전투·강화·물약 처리를 브라우저 엔진에서 실행합니다. 게임 명령마다 서버를 호출하지 않으며, 10분 자동 저장·수동 저장·정상 종료 저장으로 기록과 랭킹을 갱신합니다. +9/+10 강화와 90/99레벨 달성은 시스템 채팅을 위해 즉시 저장을 시도합니다.

- `npm test`: 149개 통과. 기존 엔진·인증·SQL·채팅과 새 체크포인트 API/저장 큐 검증을 포함합니다.
- `npm run test:e2e`: 기존 데모·연결 진단 8개 통과.
- `npm run test:e2e:online`: 온라인 흐름 6개 검증 완료. 최초 실행에서 발견한 채팅창의 복구 버튼 가림을 수정하고 해당 시나리오를 재실행해 통과했습니다.
- `npm run build`: 배포 빌드 및 TypeScript 검사 통과.
- `npm run balance -- --check`: 성장·전투·경제 기준 통과. 99레벨 예상 기사12.90시간/요정13.08시간, 화룡 +7~8 평균 가속10.26초/기본19.40초, 가속 주홍 물약2.90개입니다.

온라인 브라우저 검사는 실제 로그인 UI와 캔버스를 사용하되 인증·저장·채팅 외부 서비스만 모의 응답으로 대체했습니다. 이동과 처치 중 `/api/action` 호출0회, 800ms 이상 지연된 저장 중 계속 이동, 저장 응답이 현재 위치를 되돌리지 않음, 실패 후 같은 요청 ID 재시도, 채팅 단절·입력 분리, 정상 종료 후 저장 복원, 10분 주기, 다른 기기의 저장 충돌 후 안전한 다시 불러오기를 확인했습니다.

체크포인트는 계정·데이터 범위·버전을 검사하고 누적 처치 수를 절대값으로 저장합니다. 중복 업로드가 누적 수를 다시 더하지 않습니다. 클라이언트의 전투를 서버에서 재계산하지 않으므로 자기 진행 기록 조작을 완전히 막는 방식은 아닙니다. 탭 닫기·새로고침의 keepalive 저장은 최선의 시도이며 완료를 보장하지 않습니다.

추가 SQL·환경변수는 필요하지 않습니다. 이 작업 공간에서는 실제 서비스 계정/키를 사용할 수 없어 새 공개 배포의 실제 회원 저장·친구 간 채팅 전달은 검증하지 않았습니다. Vercel 배포 완료 후 상단의 ‘지금 저장’과 ‘마지막 저장’ 표시를 확인합니다.
